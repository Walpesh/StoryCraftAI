# StoryCraftAI - Генерация книг с помощью Искусственного Интеллекта

## 📋 Обоснование архитектуры проекта

### Почему бэкенд реализован в одном файле `main.py`?

**1. Учебный/дипломный проект:** Для демонстрации функционала и защиты диплома монолитная структура в одном файле обеспечивает:
- **Простоту понимания** - вся логика приложения находится в одном месте, что упрощает демонстрацию кода комиссии
- **Лёгкость развёртывания** - не нужно настраивать сложную структуру папок и импортов
- **Быструю навигацию** - все маршруты, модели и функции видны сразу

**2. Малый и средний масштаб:** На момент разработки проект содержит:
- ~500 строк кода
- 5 основных таблиц БД
- 10-15 маршрутов
Это вполне укладывается в один файл без потери читаемости.

**3. FastAPI отлично подходит для монолита:**
- Встроенная документация Swagger UI
- Минимальный boilerplate код
- Декоративный синтаксис маршрутов

**4. Перспективы масштабирования:** В будущем проект легко разбить на модули:
- `routers/` - для разделения маршрутов
- `models/` - для моделей данных
- `schemas/` - для Pydantic схем
- `services/` - для бизнес-логики

## 🎯 Описание проекта

**StoryCraftAI** — это веб-приложение для генерации уникальных книг и историй с помощью искусственного интеллекта (MistralAI). Платформа позволяет любому пользователю создать полноценную книгу по заданным параметрам без необходимости иметь писательские навыки.

### 🔥 Основные возможности

#### Для пользователей:
- ✅ **Генерация книг** по параметрам (жанр, длина, тон, точка зрения, тип финала)
- ✅ **Личная библиотека** - хранение всех созданных книг
- ✅ **Система отзывов** - комментирование книг других пользователей
- ✅ **История генераций** с датами и параметрами
- ✅ **Фильтрация контента** - автоматическая блокировка запрещённого контента (18+, насилие, нецензурная лексика)

#### Для администраторов:
- ✅ **Управление пользователями** (бан/разбан, изменение ролей)
- ✅ **Управление книгами** (просмотр, удаление)
- ✅ **Система логирования** всех действий с фильтрацией
- ✅ **Блокировка IP-адресов** через middleware
- ✅ **Статистика платформы** (пользователи, книги, отзывы, активность)

#### Безопасность:
- 🔐 Хеширование паролей (bcrypt)
- 🔐 Сессионная авторизация через cookies
- 🔐 Система ролей (user, admin, banned)
- 🔐 Middleware для проверки IP и логирования
- 🔐 Защита от SQL-инъекций через SQLAlchemy ORM

## 🛠 Технологический стек

### Backend
- **Python 3.8+**
- **FastAPI** - современный асинхронный веб-фреймворк
- **SQLAlchemy ORM** - работа с базой данных
- **MistralAI API** - генерация текста с помощью ИИ
- **bcrypt** - хеширование паролей
- **Jinja2** - шаблонизатор для HTML

### Frontend
- **HTML5 + Jinja2 templates**
- **TailwindCSS** - утилитарный CSS-фреймворк
- **Vanilla JavaScript** - без фреймворков

### Database
- **SQLite** - для разработки (легко заменить на PostgreSQL/MySQL)

### Дополнительно
- **Middleware** - логирование, фильтрация IP
- **Background Tasks** - фоновые задачи
- **Environment variables** (.env) - безопасное хранение ключей

## 📦 Установка и запуск проекта

### Требования
- Python 3.8 или выше
- pip (менеджер пакетов Python)
- Аккаунт MistralAI и API ключ

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/Walpesh/StoryCraftAI.git
cd StoryCraftAI
```

### Шаг 2: Создание виртуального окружения

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

> **Примечание:** Если файл `requirements.txt` отсутствует, установите зависимости вручную:
```bash
pip install fastapi uvicorn sqlalchemy mistralai python-multipart python-jose[bcrypt] jinja2 aiofiles
```

### Шаг 4: Настройка переменных окружения

1. Создайте файл `.env` в корневой директории проекта:
```bash
touch .env  # Linux/macOS
# или создайте файл вручную в Windows
```

2. Добавьте следующие переменные:
```env
# MistralAI API ключ
MISTRAL_API_KEY=ваш_api_ключ_here

# Секретный ключ для сессий
SECRET_KEY=ваш_секретный_ключ_для_cookie

# Настройки базы данных
DATABASE_URL=sqlite:///./storycraft.db

# Настройки сервера
HOST=127.0.0.1
PORT=8000
```

> **Важно:** Файл `.env` добавлен в `.gitignore` и не попадает в репозиторий!

### Шаг 5: Инициализация базы данных

При первом запуске база данных создастся автоматически. Если нужно сбросить:

```bash
# Удалите существующий файл БД (если есть)
rm storycraft.db  # Linux/macOS
del storycraft.db  # Windows

# Запустите проект - БД создастся автоматически
```

### Шаг 6: Запуск сервера

**Вариант 1: Через uvicorn (рекомендуется)**
```bash
uvicorn main:app --reload --host 127.0.0.1 --port 8000
```

**Вариант 2: Через bat-файл (Windows)**
```bash
start_server.bat
```

**Вариант 3: Через Python**
```bash
python main.py
```

### Шаг 7: Открытие приложения

Перейдите в браузере по адресу:
- **Основное приложение:** http://127.0.0.1:8000
- **API документация (Swagger):** http://127.0.0.1:8000/docs
- **Альтернативная документация (ReDoc):** http://127.0.0.1:8000/redoc

##  Структура базы данных

### Таблица `users` (Пользователи)
- `id` - первичный ключ
- `username` - уникальное имя пользователя
- `email` - уникальный email
- `hashed_password` - хешированный пароль
- `created_at` - дата регистрации
- `last_generated_at` - дата последней генерации
- `account_type` - роль (user/admin/banned)

### Таблица `books` (Книги)
- `id` - первичный ключ
- `title` - название книги
- `genre` - жанр
- `author_name` - имя автора
- `content` - содержимое книги
- `created_at` - дата создания
- `is_published` - статус публикации
- `language` - язык
- `tone` - тон повествования
- `point_of_view` - точка зрения
- `user_id` - внешний ключ на users

### Таблица `logs` (Логи)
- `id` - первичный ключ
- `action` - описание действия
- `action_type` - тип действия
- `user_id` - внешний ключ на users
- `ip_address` - IP-адрес
- `created_at` - дата и время

### Таблица `blocked_ips` (Заблокированные IP)
- `id` - первичный ключ
- `ip_address` - IP-адрес (уникальный)
- `blocked_at` - дата блокировки

### Таблица `feedback` (Отзывы)
- `id` - первичный ключ
- `user_id` - внешний ключ на users
- `text` - текст отзыва
- `created_at` - дата создания
- `updated_at` - дата обновления

## 🔑 Основные маршруты API

### Публичные маршруты
- `GET /` - главная страница
- `GET /login` - страница входа
- `POST /login` - авторизация
- `GET /register` - страница регистрации
- `POST /register` - регистрация нового пользователя

### Защищённые маршруты (требуют авторизации)
- `GET /generate` - страница генерации книги
- `POST /generate_book` - генерация книги через MistralAI
- `GET /library` - личная библиотека пользователя
- `GET /book/{id}` - просмотр конкретной книги
- `POST /feedback` - оставить отзыв
- `PUT /feedback/{id}` - редактировать отзыв
- `DELETE /feedback/{id}` - удалить отзыв

### Административные маршруты (только admin)
- `GET /admin` - панель администратора
- `GET /admin/users` - управление пользователями
- `POST /admin/ban/{id}` - забанить пользователя
- `POST /admin/unban/{id}` - разбанить пользователя
- `POST /admin/change_role/{id}` - изменить роль
- `DELETE /admin/book/{id}` - удалить книгу
- `GET /admin/logs` - просмотр логов
- `POST /admin/block_ip` - заблокировать IP

##  Примеры использования

### Генерация книги

1. Авторизуйтесь в системе
2. Перейдите на страницу "Создать книгу"
3. Заполните параметры:
   - **Название:** "Приключения в космосе"
   - **Жанр:** Фантастика
   - **Описание:** "История о первом контакте с инопланетной цивилизацией"
   - **Длина:** Средняя
   - **Тон:** Приключенческий
   - **Точка зрения:** От третьего лица
   - **Финал:** Счастливый
4. Нажмите "Сгенерировать"
5. Через несколько секунд книга появится в вашей библиотеке

### Работа в админ-панели

1. Войдите под учётной записью администратора
2. Перейдите в `/admin`
3. Доступные действия:
   - Просмотр всех пользователей
   - Бан/разбан нарушителей
   - Удаление нежелательного контента
   - Анализ логов активности
   - Блокировка подозрительных IP

## 🔐 Система безопасности

### Фильтрация контента
Перед отправкой запроса в MistralAI происходит проверка промта на наличие:
- Нецензурной лексики
- Призывов к насилию
- Контента 18+
- Других запрещённых тем

При обнаружении нарушений:
- Запрос блокируется
- Пользователю предлагается безопасная альтернатива
- Действие логируется

### Защита сессий
- Cookies с HttpOnly флагом
- Хеширование паролей bcrypt
- Проверка роли на каждом запросе
- Middleware для проверки IP

### Логирование
Все действия пользователей записываются в базу:
- Вход/выход из системы
- Регистрация
- Генерация книг
- Создание/редактирование отзывов
- Административные действия
